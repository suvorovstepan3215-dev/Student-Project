# Статус проекта: мультиагентный сбор медицинской информации

Курс: F[26] «Программная инженерия мультиагентных ИИ-систем в медицине».
Семинар: **13.11, 17:40–20:40**. Требование: два согласованных источника,
веб-интерфейс, публичное размещение, доклад и презентация.

Этот файл заменяет устаревшие утверждения предыдущего плана: о якобы
отсутствующем API Минздрава, вымышленной дате 1 января, игнорировании
однолетнего фильтра и необходимости ещё добавлять уже существующие tools.

## Выбранные источники

1. **Europe PMC** — биомедицинские публикации, REST, аннотации и метаданные.
2. **Рубрикатор клинических рекомендаций Минздрава РФ** — каталог КР.

Источники были отправлены на согласование; ответ преподавателя в этой
сессии не предоставлен. **Стороннее зеркало не следует выдавать за
проверенный официальный источник** или автоматически считать согласованным.

## Реализовано в `Лекция_3`

- [x] Шесть адаптеров: Europe PMC, Минздрав, archive.org, arXiv, OpenAlex, Habr.
- [x] По умолчанию выбраны два источника задания; темы `diabetes` / `сахарный диабет`.
- [x] Оркестратор, лексический валидатор с русскими основами, резюме EN/RU.
- [x] Streamlit: поиск, карточки/таблица, методы резюме, ошибки и происхождение данных.
- [x] MCP stdio: девять tools, сервисный слой и настоящий отдельный клиент.
- [x] Документация локального запуска, Windows/macOS/Linux, Cherry Studio и облачного размещения.

## Исправления по аудиту (12.11)

- [x] Europe PMC: серверная сортировка новых записей, курсоры,
      сохранение препринтов без DOI/PMID, сообщения о неполной выдаче.
- [x] Минздрав: добавлен адаптер официального каталога `GetJsonClinrecsFilterV2`;
      режимы `official` / `mirror` / `auto`, явное предупреждение при fallback.
      **Живая доступность API в среде разработки не подтверждена**;
      схема/пагинация проверяются на синтетических фикстурах.
- [x] Зеркало: пагинация классов МКБ-10, паузы, ограничения обхода,
      TTL/ключ кэша по режиму и URL, отсутствие вечного кэша пустых/неполных ответов.
- [x] У зеркала год остаётся годом; фильтр применяется всегда, в том числе
      в одном году. У API дата реестра не называется годом пересмотра.
- [x] Метаданные КР помечаются `metadata_only`: описание карточки не
      подаётся как резюме полного текста, официальный ID не выдумывается.
- [x] Короткая аннотация не заменяется меню сайта. Полные тексты КР не загружаются.
- [x] Настоящий EN/RU LSA работает без загружаемых данных NLTK через автономный
      токенизатор. Первые предложения — только явный резервный метод.
- [x] Ошибки источников/отдельных тем/страниц видны в UI и MCP;
      недоступность источника не превращается в успешный пустой поиск.
- [x] Защита от пересылки серверного секрета на произвольный LLM URL:
      только серверные пресеты, нет записи конфигурации из публичного UI,
      LLM отключены для анонимного веб-режима по умолчанию.
- [x] Ограниченные HTTP-запросы, проверка URL/DNS/IP и каждого redirect,
      запрет частных адресов для источников, сохранение TLS-проверки,
      безопасный XML; маскирование/ротация логов.
- [x] История UI — только сеанс; CLI — атомарная запись под блокировкой
      после успешного резюме/уведомления. Убрано межсеансовое состояние функции.
- [x] Планировщик запускает первый цикл сразу, без перекрытий.
      Проверка LLM учитывает HTTP-статус, авторизацию и выбранную модель.
- [x] Совместимая версия MCP 2.3.0, обновлённые зависимости и проверка известных
      уязвимостей; переносимые shell-скрипты и исправленные SMTP-поля.
- [x] Регрессионные pytest-проверки, включая Streamlit AppTest,
      реальный MCP stdio и негативные security-тесты; CI для Python 3.11/3.12.
      Локальный прогон выполняется на Python 3.11; результаты CI — отдельная проверка.
